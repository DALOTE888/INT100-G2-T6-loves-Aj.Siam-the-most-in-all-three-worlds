# POINT OF VIEW (POV)

- We Met : พวกเราได้ลงพื้นที่สังเกตการณ์และพูดคุยกับผู้ใช้งานหลากหลายกลุ่ม (ทั้งวัยทำงานที่มาออกกำลังกายหลังเลิกงาน, ผู้สูงอายุที่มาพบปะสังสรรค์ในช่วงสาย, และผู้ใช้บริการประจำ) ที่ใช้พื้นที่สาธารณะใกล้บ้านในการดูแลสุขภาพ

- We Were Surprised To Notice : จากที่ได้สอบถามผู้ใช้งานหลายๆกลุ่ม ต่างบอกตรงกันว่าปัญหาด้านความเสื่อมโทรมของห้องน้ำไม่สะอาดและไม่มีสายฉีด, ม้านั่งพัง, ตู้น้ำดื่มที่ต้องลุ้น, และการขาดการบำรุงรักษา จนทำให้เกิดความอึดอัดและกังวลใจลึกๆ แต่พวกเขากลับยังคงแสดงสีหน้ายิ้มแย้ม เป็นกันเอง

- We Wonder If This Means : หากปล่อยให้ผู้ใช้งานต้องทนรับสภาพความเสื่อมโทรมเหล่านี้ต่อไปเรื่อยๆ ความสุข ความผูกพัน และความตั้งใจในการมาดูแลสุขภาพของพวกเขาอาจค่อยๆ ลดลง จนกลายเป็นความรู้สึกถูกละเลยจากหน่วยงานหรือผู้ดูแลสถานที่ในที่สุด

- It Would Be Game-Changing To : พัฒนาระบบการดูแลเชิงรุก (กระบวนการจัดการเรียนการสอนที่ให้ผู้เรียนมีส่วนร่วมและลงมือปฏิบัติจริงผ่านกิจกรรม) และเปิดให้ชุมชนมีส่วนร่วมในการบริหารจัดการ เพื่อยกระดับสุขอนามัยและความปลอดภัยให้ตอบโจทย์การใช้งานจริงอย่างยั่งยืน
