## กลุ่ม 1

### SAY :

- สุขภาพไม่ค่อยดี เลยมาออกกำลังกาย
- ใกล้บ้านเพราะอยู่แถวนี้
- ความสะอาดของตู้น้ำพอใช้ได้

### DO :

- ออกกำลังกาย 4-5 วันต่อสัปดาห์
- นำน้ำจากบ้านมาเติมที่ตู้เอง

### THINK :

- อยากให้ปรับปรุงความสะอาดของห้องน้ำ


### FEEL :

- ปกติ ไม่ได้แสดงความเครียด

## กลุ่ม 2

### SAY :

- มาวิ่งทุกวันช่วงเย็น เพราะตอนเช้าทำงาน
- บ้านอยู่ใกล้
- โดยรวมไม่ค่อยมีปัญหา เพราะมาแค่วิ่ง
- ห้องน้ำไม่มีปัญหาอะไร

### DO :

- วิ่งออกกำลังกาย
- มาคนเดียวเป็นส่วนใหญ่ พาหลานมาบ้างเป็นบางครั้ง

### THINK :

- ไม่ค่อยมีปัญหาในการมาออกกำลังกาย
- ที่นั่งมีแทบทุกจุด


### FEEL :

- ยิ้มแย้ม

## กลุ่ม 3

### SAY :

- ห้องน้ำไม่ค่อยสะอาด  
- ตอนเย็นคนใช้เยอะ แต่ไม่ค่อยมีคนมาทำความสะอาด คนทำไม่ไหว
- สถานที่ขายอาหารอยู่ค่อนข้างไกล 
- มาทุกวัน เพราะบ้านอยู่ใกล้

### DO :

- วิ่งและเดินออกกำลังกาย
- นั่งชิลๆ

### THINK :

- ต้องการให้ดูแลความสะอาดห้องน้ำมากขึ้น
- อยากให้มีร้านอาหารหรือของกินที่เข้าถึงได้ง่ายขึ้น


### FEEL :

- ยิ้ม เป็นกันเอง

## กลุ่ม 4

### SAY :

- ห้องน้ำไม่ค่อยสะอาดและไม่ค่อยปลอดภัยสำหรับผู้สูงอายุ
- ม้านั่งพังและไม่ค่อยมาซ่อม
- บ้านอยู่ใกล้ที่สุด

### DO :

- มาออกกำลังกายทุกวัน ยกเว้นวันอาทิตย์
- เดินออกกำลังกายช่วง 10:00–12:00 น.
- มาคนเดียวหรือบางครั้งมากับกลุ่มเพื่อน

### THINK :

- ต้องการให้ปรับปรุงห้องน้ำให้ปลอดภัยสำหรับผู้สูงอายุ
- ต้องการให้ซ่อมแซมม้านั่ง


### FEEL :

- ยิ้มแย้ม เป็นกันเอง
